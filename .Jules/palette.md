## 2024-07-02 - Keyboard Shortcuts for Multi-Drawer Dashboards
**Learning:** For interfaces using perimeter drawers (Top, Left, Right, Bottom), mapping mnemonics (T, L, R, B) as global shortcuts significantly improves navigational efficiency for power users. Including visible hints like `[L] LABEL` in the UI aids discoverability.
**Action:** Always include a conditional check to ignore global shortcuts when the user is focused on `INPUT`, `TEXTAREA`, or `SELECT` elements to prevent accidental activation while typing.
