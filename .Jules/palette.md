## 2025-05-15 - [Accessible Drawers and Keyboard Shortcuts]
**Learning:** For immersive, full-screen AI studios, navigational keyboard shortcuts (T, L, R, B) significantly improve the power-user experience, but must be accompanied by visible hints to be discoverable.
**Action:** Always provide visible keyboard shortcut hints (e.g., [L] for Left) in labels or tooltips when implementing global hotkeys.
