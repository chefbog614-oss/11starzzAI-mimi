## 2025-05-18 - Shell Command History and Escape Drawer Management

**Learning:** Terminal inputs in Web interfaces feel unresponsive without standard CLI command history navigation (`ArrowUp`/`ArrowDown`). Combining this with a global `Escape` key handler to dismiss side drawers improves accessibility and keyboard workflow for power users.

**Action:** Always pair terminal-style inputs with `commandHistory` array navigation and include `Escape` key dismissal for overlay panels.
